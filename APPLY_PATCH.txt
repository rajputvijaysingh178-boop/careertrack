CHANGES
- A submitted skill profile is no longer erased if every submitted skill is unknown to the master catalog. Explicitly submitting an empty list still clears the profile.
- If the skill catalog is empty or unavailable, the API returns HTTP 503 and does not change the saved profile.
- The recommendations UI keeps submitted text visible and explains that unknown skills must be added in Admin -> Skills.
- Empty recommendations now explain that applied/ignored jobs are excluded and that jobs need linked skills.
- Added regression tests for unknown skills, unavailable catalog, and explicit profile clearing.
